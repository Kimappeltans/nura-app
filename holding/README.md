# Holding page

What risewithnura.com shows until the landing page (`nura-site/`) is ready.
Deploy: copy this folder plus `public/fonts/` and `nura-site/assets/ra-hello.webp`
into one folder and `netlify deploy --prod --dir` it to the nura-site-338 site.
To launch, deploy `nura-site/` there instead (or publish its earlier deploy in Netlify).
